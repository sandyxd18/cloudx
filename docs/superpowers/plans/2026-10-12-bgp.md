# BGP (BIRD) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task.

**Goal:** Menjadikan `bgp-peers` nyata: sesi eBGP via BIRD di netns per router, advertise `advertised_prefixes`, dan route yang dipelajari masuk ke OVN.

**Architecture:** Pola identik VPNaaS: `bgp-worker` polling `/internal/bgp-agent/{host}` per 5 s, menjalankan satu `bird` per router di netns `qbgp-<short>`, melapor status + route; API merekonsiliasi route ke OVN.

**Tech Stack:** FastAPI/SQLAlchemy/Alembic, OVN (`ovn_cli`), `shared.proc.run`, bird2 2.14.

**Spec:** `docs/superpowers/specs/2026-10-12-bgp-design.md`. Spike: `docs/superpowers/plans/bgp-spike-notes.md`. Referensi kode: `services/networking/app/routers/vpn.py`, `services/vpn_worker/app/main.py`, `tests/vpn_worker/test_reconcile.py`, `tests/networking/test_vpn_gateway.py`.

## Global Constraints

- Tanpa commit/push, tanpa `git checkout/stash/restore/reset`, tanpa file scratch di root repo.
- Setiap `except Exception` lebar wajib `# best-effort: <alasan>`; panggil proses lewat `shared.proc.run`, bukan `subprocess`.
- Endpoint internal memakai `dependencies=[InternalAuth]` (bukan token string manual). Worker mengirim kunci `status` dan `status_reason`; endpoint membaca kunci yang sama.
- Host speaker = hostname chassis (`vpn._get_router_host(router.name)`), bukan UUID.
- Password tidak pernah ke log/argv; file `bird.conf` mode 0600.
- Test worker mem-patch `bgp_worker.run` (nama yang diimpor worker), bukan `shared.proc.run`, dan menegaskan argv eksak. Setiap invarian punya mutation check yang ditunjukkan gagal.
- Short id: `gw_id.split("-",1)[1][:8]`; ID speaker `bgpsp-<12 hex>`; nama Linux ifname <= 15 karakter.
- Model dan migrasi harus identik (`tests/shared/test_migrations.py`); tanpa FK pada kolom tambahan di `networking_bgp_peers` (SQLite tidak bisa ALTER constraint).
- Selalu jalankan SUITE PENUH sebelum lapor: `python -m pytest tests/networking tests/shared tests/cli tests/bgp_worker tests/vpn_worker -q -W ignore` dengan env `AUTH_SECRET_KEY=x*32`, `AUTH_ADMIN_PASSWORD=x`, `KEY_MANAGER_MASTER_KEY=x*32`, `REVOCATION_CHECK=false`, `STORAGE_LVM_DRIVER=true`; ditambah `ruff check services cli tests --select F401,F811,F821 --exclude "node_modules,migrations/versions"`.

## Review Focus

- Router tanpa external gateway: 400, tanpa objek OVN tersisa.
- Dua peer di router yang sama dengan `local_as` berbeda: 409.
- Peer terakhir dihapus saat route learned ada: semua route OVN milik peer ditarik sebelum speaker dihapus.
- Peer `down` / bird mati: route learned ditarik, route statis lain di router tidak tersentuh.
- Route learned berupa default (`0.0.0.0/0`), menimpa subnet router, atau nexthop di luar subnet eksternal: diabaikan.
- Restart worker: re-adopt netns/port/bird yang ada tanpa duplikat.
